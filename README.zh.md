# Metis — 快速开始（中文）

**Metis** (μῆτις) — 覆盖任意 LLM 的分布式认知层。

🌐 语言: [English](README.md) · [Русский](README.ru.md) · [Español](README.es.md) · [Français](README.fr.md) · **中文**

## 在线演示

打开 **[metis.modelmarket.dev](https://metis.modelmarket.dev/)** — 3D 星体、聊天与认知图。

## 安装

PyPI 包名为 **`aimarket-metis`**。

```bash
pip install aimarket-metis
```

## 第一条命令

```bash
metis "解释多智能体系统" --model qwen3:8b --url http://localhost:11434/v1
```
