# Metis — démarrage rapide (FR)

**Metis** (μῆτις) — couche cognitive distribuée au-dessus de n’importe quel LLM.

🌐 Langue: [English](README.md) · [Русский](README.ru.md) · [Español](README.es.md) · **Français** · [中文](README.zh.md)

## Démo live

Ouvrez **[metis.modelmarket.dev](https://metis.modelmarket.dev/)** — étoile 3D, chat et graphe de cognition.

## Installer

Le paquet PyPI s’appelle **`aimarket-metis`**.

```bash
pip install aimarket-metis
```

## Première commande

```bash
metis "Explique les systèmes multi-agents" --model qwen3:8b --url http://localhost:11434/v1
```
